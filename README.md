# Healthcare Appointment Booking Platform

A modern healthcare appointment booking platform built with Angular 21.

This project focuses on providing a fast, clean and intuitive experience for patients to find doctors, hospitals and book appointments.

# Development Principles

- Build reusable components.
- Prefer Angular Signals.
- Keep UI components independent.
- Avoid duplicated code.
- Design for scalability.
- Mobile responsive.
- Production-ready code.

---

# Current Development Rule

Until UI/UX is finalized:

- No backend integration.
- No real APIs.
- No database dependency.

Every page should use dummy/hardcoded data stored inside the feature component or a dedicated mock data folder.

API integration will start only after all user journeys are complete.
